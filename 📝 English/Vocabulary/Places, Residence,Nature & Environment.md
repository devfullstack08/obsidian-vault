# Nature & Environment

| Word              | Type | Meaning                                                                |     |     |
| ----------------- | ---- | ---------------------------------------------------------------------- | --- | --- |
| Flora             | Noun | Plants of a particular region or period.                               |     |     |
| Fauna             | Noun | Animals of a particular region or period.                              |     |     |
| Ecosystem         | Noun | A community of living organisms and their environment.                 |     |     |
| Biodiversity      | Noun | Variety of plant and animal life in an area.                           |     |     |
| Habitat           | Noun | Natural home of a plant or animal.                                     |     |     |
| Environment       | Noun | Surroundings in which living beings live.                              |     |     |
| Conservation      | Noun | Protection and careful use of natural resources.                       |     |     |
| Deforestation     | Noun | Large-scale cutting of forests.                                        |     |     |
| Afforestation     | Noun | Planting trees in an area where there were no forests.                 |     |     |
| Reforestation     | Noun | Replanting trees in a deforested area.                                 |     |     |
| Pollution         | Noun | Contamination of air, water, or land.                                  |     |     |
| Greenhouse Effect | Noun | Warming of Earth due to trapping of heat by gases.                     |     |     |
| Global Warming    | Noun | Rise in Earth’s average temperature.                                   |     |     |
| Climate Change    | Noun | Long-term change in climate patterns.                                  |     |     |
| Ozone Layer       | Noun | Layer in the atmosphere that protects Earth from harmful UV rays.      |     |     |
| Acid Rain         | Noun | Rain containing harmful acids due to pollution.                        |     |     |
| Desertification   | Noun | Process by which fertile land becomes desert.                          |     |     |
| Erosion           | Noun | Wearing away of soil or rock by wind, water, or ice.                   |     |     |
| Drought           | Noun | Long period with little or no rainfall.                                |     |     |
| Flood             | Noun | Overflow of water over normally dry land.                              |     |     |
| Cyclone           | Noun | Violent rotating storm with strong winds.                              |     |     |
| Tsunami           | Noun | Huge sea wave caused by earthquake or volcanic activity under the sea. |     |     |
| Volcano           | Noun | Opening in Earth’s crust through which lava and gases come out.        |     |     |
| Earthquake        | Noun | Sudden shaking of the Earth’s surface.                                 |     |     |
| Avalanche         | Noun | Sudden fall of snow, ice, or rocks down a mountain.                    |     |     |
| Glacier           | Noun | Large slow-moving mass of ice.                                         |     |     |
| Delta             | Noun | Landform made by river deposits near its mouth.                        |     |     |
| Estuary           | Noun | Area where a river meets the sea.                                      |     |     |
| Lagoon            | Noun | Shallow water body separated from the sea by sand or coral.            |     |     |
| Peninsula(3)      | Noun | Land surrounded by water on three sides.                               |     |     |
| Island(4)         | Noun | Land surrounded by water on all sides.                                 |     |     |
| Strait            | Noun | Narrow water passage connecting two large water bodies.                |     |     |
| Isthmus           | Noun | Narrow strip of land connecting two larger land areas.                 |     |     |
| Archipelago       | Noun | Group of islands.                                                      |     |     |
| Plateau           | Noun | High flat land.                                                        |     |     |
| Plain             | Noun | Large area of flat land.                                               |     |     |
| Valley            | Noun | Low land between hills or mountains.                                   |     |     |
| Gorge             | Noun | Deep narrow valley with steep sides.                                   |     |     |
| Gulf              | Noun | A large area of sea partly surrounded by land.                         |     |     |
| Bay               | Noun | A broad inlet of sea where land curves inward.                         |     |     |

| Hometown     | Noun | The town where a person was born or grew up.                          |     |
| Native Place | Noun | The place where a person originally belongs.                          |     |

| Town         | Noun | A place larger than a village but smaller than a city.                |     |

| State        | Noun | A political unit within a country.                                    |     |
| Territory    | Noun | An area of land under a government or ruler.                          |     |
| Nation       | Noun | A large group of people with common identity, culture, or government. |     |
| Country      | Noun | A nation with its own government and territory.                       |     |
| Continent    | Noun | One of the large landmasses of the Earth.                             |     |

| Coast        | Noun | Land beside the sea.                                                  |     |
