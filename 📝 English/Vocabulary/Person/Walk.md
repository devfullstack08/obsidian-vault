## Aimless walker / no fixed home

| Word          | Type     | Meaning                                           | Where we use it                                                  |
| ------------- | -------- | ------------------------------------------------- | ---------------------------------------------------------------- |
| **Loiterer**  | noun     | Hangs around one place with no purpose.           | Street, station, shop. Often negative: *No loitering.*           |
| **Lingerer**  | noun     | Stays longer than needed.                         | After class, after a party, near someone.                        |
| **Wanderer**  | noun     | Walks without a fixed direction.                  | Neutral: *a wanderer in the hills.*                              |
| **Vagabond**  | noun     | Homeless wanderer; often poetic. Hindi **आवारा**. | Songs, stories, romance.                                         |
| **Nomad**     | noun     | Moves from place to place as a way of life.       | Tribes, herders.                                                 |
| **Drifter**   | noun     | No fixed job or home; moves town to town.         | Modern, a bit empty: *He became a drifter after losing his job.* |
| **Vagrant**   | noun     | Official word for a homeless street wanderer.     | Police, law, news. Formal and negative.                          |
| **Tramp**     | noun     | Old homeless walker from place to place.          | British / old novels.                                            |
| **Rover**     | noun     | Someone who likes to roam.                        | Mild / romantic: *a rover at heart.*                             |
| **Wayfarer**  | noun     | A traveller on foot.                              | Literary / old.                                                  |
| **Itinerant** | noun/adj | Travels for work.                                 | *itinerant worker / preacher.*                                   |
| **Migrant**   | noun     | Moves to live or work in another place.           | Jobs, cities. Not aimless.                                       |
| **Loafer**    | noun     | Idle person; wastes time.                         | Negative: *a street loafer.*                                     |
|               |          |                                                   |                                                                  |

**आवारा / romantic wanderer** → **vagabond**, sometimes **rover**  
**खानाबदोश / moving tribe** → **nomad**  
**no job, no roots, town to town** → **drifter**  
**hanging around one place** → **loiterer**  
**staying too long** → **lingerer**  
**homeless in official English** → **vagrant**

---

A very useful grouping is:

**Relaxed walk:** stroll, saunter, amble  
**Tired/heavy walk:** trudge, plod, slog  
**Unsteady walk:** stagger, totter, hobble, limp  
**Proud walk:** strut, swagger, stalk  
**Secret/quiet walk:** creep, sneak, slink, tiptoe  
**Aimless walk:** wander, roam, ramble, meander, loiter, linger, stray  
**Aimless person:** loiterer, lingerer, wanderer, vagabond, drifter  
**Long walk:** hike, trek  
**Quick movement:** scurry, scuttle, dash, bolt

For exam memory, learn them in these families rather than alphabetically.
