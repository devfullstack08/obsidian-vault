## Sadness

Sad — adjective  
Sadly — adverb  
Sadness — noun

| Word | Meaning |
| ---- | ------- |
| **Sorrow / sorrowful** | દુઃખ / શોક; deep sadness |
| **Melancholy** | Deep, quiet, thoughtful sadness |
| **Dejected** | Sad because of failure, disappointment, or rejection |
| **Despondent** | Very unhappy and without hope |
| **Gloomy** | Sad, dark, depressing |
| **Dismal / bleak** | Very bad + depressing |
| **Downcast** | Sad, shown on the face / lowered eyes |
| **Miserable** | Very unhappy or suffering |
| **Poignant** | Touching sadness; moves the heart |
| **Tranquil** | Calm + peaceful + undisturbed. Noun: **tranquility**. Adverb: **tranquilly**. |

Easy scale:

**Sad < Dejected < Despondent**

- **Sad** = unhappy
- **Dejected** = sad after disappointment
- **Downcast** = looks sad
- **Despondent** = sad + almost no hope
- **Melancholy** = deep, quiet sadness
- **Gloomy** = sad and dark
- **Dismal** = depressing and often very bad
- **Poignant** = touching sadness

Do not mix **miserable** with **mesmerise** (મંત્રમુગ્ધ કરવું).
