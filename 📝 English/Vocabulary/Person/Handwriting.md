Important SSC-style pairs:

- **Legible** = easy to read
    
- **Illegible** = impossible/difficult to read
    
- **Calligraphy** = beautiful decorative handwriting
    
- **Penmanship** = skill/style of handwriting
    
- **Scrawl** = very untidy handwriting
    
- **Scribble** = careless quick writing
    
- **Cursive** = joined handwriting
    
- **Manuscript** = handwritten/original document
    

A very useful memory group is:

**Good handwriting:** neat, legible, calligraphic  
**Bad handwriting:** messy, illegible, scrawled, scribbled  
**Style:** cursive, print, script  
**Skill/art:** penmanship, calligraphy
