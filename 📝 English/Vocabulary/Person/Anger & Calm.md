| **Resentment**       | Anger caused by unfair treatment                    |
| **Pique**            | Annoyance, especially from wounded pride            |
| **Grudge**           | Persistent resentment against someone               |

| **Outrage**          | Strong anger caused by something shocking or unjust |
| **In high dudgeon**  | In an offended and angry state                      |

**Irascible** = easily becomes angry  
**Indignant** = angry because something is unfair  
**Livid** = extremely angry  
**Wrathful** = full of intense anger  
**Petulant** = childishly bad-tempered  
**Resentful** = continuing anger because of unfair treatment  
**Irate** = very angry
Irritated → Annoyed → Angry → Irate → Furious → Livid / Enraged

And a cause-based distinction:

**Indignant** → injustice/insult  
**Pique** → hurt pride  
**Resentment** → unfair treatment remembered  
**Grudge** → resentment kept for a long time
