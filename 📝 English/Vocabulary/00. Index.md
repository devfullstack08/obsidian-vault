## Rule for a new word

Put the word in the **topic file**, not in `Untitled`.

Ask: *what is this word about?*

| If the word is about | Put it here |
| -------------------- | ----------- |
| Animal / bird | [[Animal/00. Index\|Animal]] |
| Feeling | [[Person/Feeling]] |
| Character of a person | [[Person/Character & Personality]] |
| Time / how often | [[Time & Frequency]] |
| Doing / controlling | [[Action]] |
| Work / writing / output | [[Work]] |
| Death / war / kill | [[Violence, Killing & War]] |
| Place / nature | [[Geography/Nature & Environment (કુદરત અને પર્યાવરણ)\|Geography]] |

Do **not** make a new file for one word. Do **not** drop words on the vault root.
