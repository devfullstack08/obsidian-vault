Open this first. Then open **one folder**, not the whole Vocabulary.

## Rule for a new word

Put the word in an **existing topic file**.

Do **not** make a new file for one word.  
Do **not** use Untitled.  
Do **not** drop a note on the vault root.

| If the word is about | Folder |
| -------------------- | ------ |
| Animal / bird | [[Animal/00. Index\|1. Animal]] |
| Feeling / character / body / speech | [[Person/00. Index\|2. Person]] |
| Place / water / earth / farming | [[Geography/00. Index\|3. Geography]] |
| Plant / tree / flower | [[Vegetation or Plant Life/00. Index\|4. Vegetation]] |
| Government / society (polity) | [[Polity/00. Index\|5. Polity]] |
| Time / action / work / travel | [[Time Action Work/00. Index\|6. Time, Action, Work]] |
| Crime / money / society | [[Crime Society/00. Index\|7. Crime and Society]] |
| Food / school / things at home | [[Everyday/00. Index\|8. Everyday]] |
| Meaning / spelling / phobia / science | [[Language/00. Index\|9. Language]] |
