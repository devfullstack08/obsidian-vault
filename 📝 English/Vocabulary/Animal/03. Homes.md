### Places for many animals

| Place | For |
| ----- | --- |
| **Zoo / menagerie** | wild animals shown to the public |
| **Aviary** | birds |
| **Apiary** | bees |
| **Aquarium** | fish |
| **Stable** | horses |
| **Kennel** | dogs |
| **Sty** | pigs |
| **Cowshed / byre** | cows |
| **Fold / pen** | sheep |
| **Hutch** | rabbits |
| **Abattoir / slaughterhouse** | animals killed for meat |

**Lair** = home of a wild / fierce animal.  
**Den** = lion, wolf, bear.  
**Burrow** = hole dug by a small animal, especially a rabbit.
