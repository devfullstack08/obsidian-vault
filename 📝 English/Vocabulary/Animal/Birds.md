A **bird** has feathers, wings, and a beak. It lays eggs.  
Study of birds = **ornithology**. Place for birds = **aviary**. Home = **nest**.

## Common birds for SSC

| Bird                    | Note                                                              |
| ----------------------- | ----------------------------------------------------------------- |
| **Sparrow**             | Small common bird                                                 |
| **Crow**                | Black; sound = caw                                                |

| **Parrot**              | Can copy human speech                                             |
| **Owl**                 | Nocturnal; sound = hoot                                           |

| **Vulture**             | Scavenger                                                         |
| **Hawk / falcon**       | Birds of prey                                                     |

| **Crane**               | Long legs; some migrate                                           |
| **Stork**               | Long-legged wading bird                                           |
| **Pelican**             | Large pouch in the beak                                           |
| **Penguin**             | Flightless; lives in cold regions                                 |
| **Ostrich**             | Largest bird; cannot fly                                          |
| **Kiwi**                | Flightless bird of New Zealand                                    |
| **Emu**                 | Flightless bird of Australia                                      |
| **Hen / rooster**       | Domestic fowl                                                     |
| **Duck / goose / swan** | Water birds                                                       |
| **Albatross**           | Very large sea bird with long narrow wings. Also: a heavy burden. |
| **Kingfisher**          | Dives for fish                                                    |
