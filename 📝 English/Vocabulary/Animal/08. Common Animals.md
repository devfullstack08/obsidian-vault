## Coyote

A **coyote** is a North American wild dog, smaller than a wolf. It is a carnivorous mammal.

| Word | Meaning |
| ---- | ------- |
| **Coyote** | Wild dog of North America |
| **Pup** | Young |
| **Pack** | Group |
| **Howl / yelp** | Cry |
| **Den** | Home |

Easy memory: **coyote = small American wolf / wild dog**.

## Beaver

A **beaver** is a rodent. It cuts trees with its teeth and builds a **dam** and a **lodge** in water.

| Word | Meaning |
| ---- | ------- |
| **Beaver** | Large rodent that builds dams |
| **Kit** | Young |
| **Lodge** | Home (house of sticks in water) |
| **Dam** | Wall a beaver builds across a stream |
| **Colony** | Group |
| **Beaver away** | Work hard for a long time |
| **Eager beaver** | A person who is too eager to work / please |

Easy memory: **beaver = dam + lodge + hard work**.
