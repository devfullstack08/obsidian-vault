Quick revision of the animals SSC repeats. Full tables: [[02. Male Female and Young]], [[03. Homes]], [[04. Sounds]], [[05. Collective Nouns]].

## Horse

| Word | Meaning |
| ---- | ------- |
| **Stallion** | Adult male |
| **Mare** | Adult female |
| **Foal** | Young horse / donkey / pony / mule |
| **Colt** | Young male |
| **Filly** | Young female |
| **Steed** | A horse for riding |
| **Stable / stall** | Home |
| **Stud** | Place where horses are kept for breeding |
| **Neigh** | Loud cry |
| **Whinny** | Soft / gentle neigh |
| **Herd / team** | Group |

## Donkey / mule

| Word | Meaning |
| ---- | ------- |
| **Jack / jenny** | Male / female donkey |
| **Foal** | Young |
| **Bray** | Cry |
| **Mule** | Offspring of a male donkey and a female horse |

## Easy last-minute list

Horse → stallion / mare / foal / stable / neigh  
Donkey → bray  
Cow → bull / cow / calf / herd / moo  
Sheep → ram / ewe / lamb / flock / bleat  
Goat → kid / bleat  
Pig → boar / sow / piglet / sty  
Dog → puppy / kennel / bark / pack  
Cat → kitten / mew  
Lion → lioness / cub / den / roar / pride  
Deer → stag / fawn  
Fox → vixen  
Swan → cygnet  
Goose → gosling / gaggle  
Bee → hive / swarm / apiary  
Fish → shoal  
Bird → nest / flock / aviary
