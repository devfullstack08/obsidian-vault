**pro-** = forward / in favour of / beforehand

| Word            | Built from                | Easy memory                                                               |
| --------------- | ------------------------- | ------------------------------------------------------------------------- |
| **Provident**   | *pro* + *videre* (to see) | looks **forward**; saves and plans. Full row: [[Economical#\|Economical]] |
| **Improvident** | *im-* (not) + provident   | does **not** look ahead.                                                  |

---

Exam pair:

- **Provident** = careful about the future, especially money.
- **Improvident** = careless about the future; spends without planning.
