These verbs look similar. The main check is: **does it take an object?** See [[Transitive and Intransitive Verb]].

**I** = intransitive = no object  
**T** = transitive = needs an object

---

## Fall / Fell

| Verb | V1 | V2 | V3 | Type | Meaning |
| ---- | -- | -- | -- | ---- | ------- |
| **fall** | fall | fell | fallen | I | drop down |
| **fell** | fell | felled | felled | T | cut down a tree |

> He **fell** from the tree.  
> The woodcutter **felled** the tree.

---

## Rise / Raise / Arise

| Verb | V1 | V2 | V3 | Type | Meaning |
| ---- | -- | -- | -- | ---- | ------- |
| **rise** | rise | rose | risen | I | go up by itself |
| **raise** | raise | raised | raised | T | lift something / increase |
| **arise** | arise | arose | arisen | I | a problem / situation starts |

> The sun **rises** in the east.  
> Please **raise** your hand.  
> A new problem **arose**.

Easy memory:

**rise = खुद उठना**  
**raise = किसी को उठाना**

---

## Lie / Lay

| Verb | V1 | V2 | V3 | Type | Meaning |
| ---- | -- | -- | -- | ---- | ------- |
| **lie** | lie | lay | lain | I | rest / recline |
| **lay** | lay | laid | laid | T | put something down |
| **lie** | lie | lied | lied | I | not tell the truth |

> Lie on the bed. / He **lay** on the bed yesterday. / He has **lain** there.  
> **Lay** the book on the table. / She **laid** the book there.  
> He **lied** to me.

Easy memory:

**lie = खुद लेटना**  
**lay = किसी चीज़ को रखना**

The confusing point: **lay** is also the V2 of **lie**.

## Other common confusing verbs

| Pair | Difference | Example |
| ---- | ---------- | ------- |
| **do / make** | do = work/action; make = create | do homework / make a cake |
| **say / tell** | say = words; tell = person + words | He said that... / He told me... |
| **speak / talk** | speak = language/formal; talk = conversation | speak English / talk to a friend |
| **hear / listen** | hear = sound comes; listen = you try | I heard a noise. / Listen to me. |
| **see / look / watch** | see = eyes get it; look = you turn eyes; watch = look for some time | I saw him. / Look at this. / Watch TV. |
| **borrow / lend** | borrow = take; lend = give | I borrowed a book. / She lent me a book. |
| **bring / take** | bring = towards here; take = away from here | Bring it here. / Take it there. |
| **come / go** | come = towards the speaker; go = away | Come here. / Go there. |
| **win / beat / earn** | win = a match/prize; beat = a person/team; earn = money | win the match / beat them / earn money |
| **rob / steal** | rob = person/place; steal = thing | They robbed the bank. / He stole my bag. |
| **refuse / deny** | refuse = not accept; deny = say it is not true | He refused the offer. / He denied the charge. |
| **remember / remind** | remember = you recall; remind = you make another person recall | I remember. / Remind me. |
| **discover / invent** | discover = already there; invent = make new | discover America / invent the phone |
| **wear / put on** | wear = have on the body; put on = the action of wearing | He wears a coat. / He put on his coat. |
| **die / kill** | die = I, no object; kill = T, needs object | He died. / They killed him. |
| **await / wait** | await = T, no *for*; wait = I, use *for* | Await the result. / Wait for me. |

## Easy memory

**No object → fall, rise, lie, sit**  
**Needs object → fell (a tree), raise, lay, set**
