
| Causative verb | Structure                 | Example                      |
| -------------- | ------------------------- | ---------------------------- |
| Make           | Make + Object + V1        | She made him work.           |
| Let            | Let + Object + V1         | Let him go.                  |
| Have           | Have + Object + V1        | I had him repair the car.    |
| Get            | Get + Object + to + V1    | I got him to repair the car. |
| Help           | Help + Object + (to) + V1 | She helped me (to) solve it. |

---
Exam trap: Active vs Passive

In active voice, causative make takes the bare infinitive (V1). In passive voice, it takes to + V1.

The teacher made the students rewrite the assignment.
The students were made to rewrite the assignment.
