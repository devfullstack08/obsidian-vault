| Correct expression | Incorrect expression |
| ------------------ | -------------------- |
| good at            | good in              |
| interested in      | interested for       |
| depend on          | depend of            |
| consist of         | consist in           |
| afraid of          | afraid from          |
| married to         | married with         |
| prefer X to Y      | prefer X than Y      |
| superior to        | superior than        |
| junior to          | junior than          |
| different from     | different than       |
| comply with        | comply to            |
| capable of         | capable to           |
| responsible for    | responsible of       |
|                    |                      |
#### Example

> She is married **to** a doctor.
