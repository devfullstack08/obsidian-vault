A **modal** is a helping verb. It shows ability, permission, possibility, duty, or advice.

Common modals:

**can, could, may, might, must, shall, should, will, would, ought to, need, dare, used to**

---

## Basic structure

```text
Subject + modal + V1
```

After a modal, use **V1 only**.

No **-s**, no **to**, no **V2 / V3**.

> He **can speak** English.
> She **must go** now.

Incorrect:

- can speaks
- can spoke
- can to speak
- must goes

---

## Main uses

| Modal | Use | Example |
| ----- | --- | ------- |
| **can** | ability / informal permission | He can swim. / Can I come in? |
| **could** | past ability / polite request / possibility | He could swim at 5. / Could you help me? |
| **may** | formal permission / possibility | May I come in? / It may rain. |
| **might** | weaker possibility | It might rain. |
| **must** | strong necessity / logical certainty | You must work hard. / He must be tired. |
| **have to** | outside necessity / rule | I have to attend the class. |
| **should** | advice / duty | You should study. |
| **ought to** | advice / moral duty | You ought to help him. |
| **shall** | offer / suggestion with I/we | Shall we start? |
| **will** | future / promise / determination | I will help you. |
| **would** | polite request / imaginary | Would you like tea? / If I were rich, I would travel. |
| **used to** | past habit | He used to play cricket. |
| **need** | necessity | You need not worry. / Need I come? |
| **dare** | courage | How dare you say that? |

See also [[hypothetical or imaginary situations]] for **would / could / might** in if-clauses.

---

## Confusing pairs

**can vs could**

- can = present ability  
- could = past ability, or more polite

> I can drive.  
> I could drive when I was 16.  
> Could you open the window?

**may vs might**

- may = possible  
- might = less possible / more doubtful

> It may rain.  
> It might rain, but the sky is clear.

**must vs have to**

- must = speaker’s own strong need  
- have to = rule / outside force

> I must finish this today.  
> Students have to wear a uniform.

**must not vs need not**

- must not = prohibition  
- need not = not necessary

> You must not smoke here.  
> You need not come tomorrow.

**should vs ought to**

Almost the same. **ought to** is a little more formal / moral.

> You should respect elders.  
> You ought to respect elders.

After **ought**, keep **to**:

> ought to go ✅  
> ought go ❌

## Modal perfect

For a past action:

```text
modal + have + V3
```

> He **should have worked** harder.  
> She **must have left** early.  
> You **could have told** me.  
> He **might have forgotten**.

Incorrect:

- should have work
- should had worked
- must have lefted

---

## Passive with modals

```text
modal + be + V3
modal + have been + V3
```

> The work **can be done**.  
> The letter **must be sent**.  
> The work **should have been finished**.

See [[04. Syntax]].

---

## Easy memory

**modal + V1**  
**modal + have + V3** = past  
**modal + be + V3** = passive  
**No -s / no to / no V2 after a modal**  
Exception: **ought to**
