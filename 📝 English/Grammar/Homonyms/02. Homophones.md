**Homophones** are words that have the **same pronunciation** but have **different meanings** and usually have **different spellings**.

The word _homophone_ comes from:

- **homo** = same
    
- **phone** = sound
    

So:

> **Homophones = Same sound, different meaning.**

### Homophones and Pronunciation

Homophones sound the same **within a particular accent**.

This is important because pronunciation differs among speakers.

Some words may be homophones in one accent but not in another.

Therefore, homophones are partly dependent on pronunciation and accent.


### Why Homophones Cause Spelling Mistakes

Homophones sound the same, so learners sometimes choose the wrong spelling.

Incorrect:

> Their going to school.

Correct:

> **They're** going to school.

Why?

Because:

> They're = they are.

Another example:

Incorrect:

> I want too go home.

Correct:

> I want **to** go home.

### Examples

| Word 1 | Meaning                | Word 2 | Meaning               |
| ------ | ---------------------- | ------ | --------------------- |
| see    | to look                | sea    | large body of water   |
| right  | correct                | write  | make words with a pen |
| son    | male child             | sun    | star in the sky       |
| hear   | receive sound          | here   | this place            |
| flour  | powder used in cooking | flower | part of a plant       |
| pair   | two things             | pear   | a fruit               |
| one    | number 1               | won    | past tense of win     |
| blue   | a colour               | blew   | past tense of blow    |

### Example Sentences

> I can **see** the **sea** from my window.

> Please **write** the **right** answer.

> The **sun** is shining on my **son**.

> I can **hear** you from **here**.


## Common Homophones
| Word pair / group           | Word — Meaning                                                     | Example                                     |
| --------------------------- | ------------------------------------------------------------------ | ------------------------------------------- |
| **Their / There / They're** | **Their** — shows possession                                       | **Their** car is new.                       |
|                             | **There** — refers to a place or existence                         | Put the book over **there**.                |
|                             | **They're** — short form of _they are_                             | **They're** studying.                       |
| **Your / You're**           | **Your** — shows possession                                        | Is this **your** book?                      |
|                             | **You're** — short form of _you are_                               | **You're** very kind.                       |
| **Its / It's**              | **Its** — shows possession                                         | The dog wagged **its** tail.                |
|                             | **It's** — means _it is_ or _it has_                               | **It's** raining.                           |
| **To / Too / Two**          | **To** — shows direction or is used before a verb                  | She went **to** school.                     |
|                             | **Too** — means _also_ or _excessively_                            | This bag is **too** heavy.                  |
|                             | **Two** — the number 2                                             | I have **two** books.                       |
| **See / Sea**               | **See** — to look or perceive with the eyes                        | I can **see** the mountains.                |
|                             | **Sea** — a large body of salt water                               | The ship sailed across the **sea**.         |
| **Right / Write / Rite**    | **Right** — correct; also the opposite of left                     | Your answer is **right**.                   |
|                             | **Write** — to form words or sentences                             | Please **write** your name.                 |
|                             | **Rite** — a formal or ceremonial act                              | The ceremony is an ancient **rite**.        |
| **Son / Sun**               | **Son** — a male child                                             | Their **son** is ten years old.             |
|                             | **Sun** — the star at the centre of our solar system               | The **sun** is shining brightly.            |
| **Hear / Here**             | **Hear** — to receive sound                                        | I can **hear** music.                       |
|                             | **Here** — in this place                                           | Please come **here**.                       |
| **Flour / Flower**          | **Flour** — powder used for baking                                 | Add some **flour** to the mixture.          |
|                             | **Flower** — the blooming part of a plant                          | She picked a beautiful **flower**.          |
| **Pair / Pear**             | **Pair** — two matching or related things                          | I bought a **pair** of shoes.               |
|                             | **Pear** — a type of fruit                                         | She ate a **pear**.                         |
| **One / Won**               | **One** — the number 1                                             | I have **one** sister.                      |
|                             | **Won** — past tense of _win_                                      | Our team **won** the match.                 |
| **Blue / Blew**             | **Blue** — a colour                                                | The sky is **blue**.                        |

|                             | **Bye** — short form of _goodbye_                                  | **Bye**, see you tomorrow.                  |
| **Know / No**               | **Know** — to have knowledge of something                          | I **know** the answer.                      |
|                             | **No** — a negative response                                       | **No**, I don't agree.                      |

|                             | **Knew** — past tense of _know_                                    | I **knew** the answer.                      |
