### What is Voice?

Voice shows whether the subject **performs an action** or **receives an action**.

There are two types:

- Active Voice
- Passive Voice

### Active Voice

The subject performs the action.

**Structure:**

`Subject + Verb + Object`

Example:

> Rahul writes a letter.

- Rahul = Subject
- writes = Verb
- a letter = Object

### Passive Voice

The object receives the action.

**Structure:**

`Object + helping verb + V3 + by + Subject`

Example:

> A letter is written by Rahul.

### Main Difference
#### Active Voice

The focus is on **who performs the action**.

> The police arrested the thief.

Focus: **the police**

#### Passive Voice

The focus is on **the action or receiver of the action**.

> The thief was arrested by the police.

Focus: **the thief

---
Active = working / currently used / enabled
Passive = not actively working / waiting / inactive

## Active User vs Passive User

This is **not the same as grammatical active/passive voice**.

In software:

### Active User

A user who:

- is enabled
- can access the system
- currently uses the service

Example:

> We have 10,000 active users.

### Inactive User

A user who is:

- disabled
- not currently using the system
- inactive for a certain period

In software terminology:

✅ **Active user / Inactive user**

is usually better than:

⚠️ **Active user / Passive user**

A **passive user** can instead mean someone who uses an app but rarely interacts with it.
