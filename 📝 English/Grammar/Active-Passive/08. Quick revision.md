
1. Passive requires V3.
2. A helping verb is necessary.
3. After **by**, use the object pronoun.

## Quick Conversion Method

Whenever you see an active sentence, use these steps.

### Step 1: Find Subject, Verb, Object

> Rahul writes a letter.

Subject = Rahul

Verb = writes

Object = a letter

### Step 2: Move Object to the beginning

> A letter ...

### Step 3: Identify the tense

"writes" = Present Simple.

### Step 4: Select correct form of "be"

Present simple + singular subject:

**is**

### Step 5: Change verb into V3

write → written

### Step 6: Change original subject

Rahul → by Rahul

Final:

> A letter is written by Rahul.

##  The Master Formula

Memorize this:

### Active

**S + V + O**

### Passive

**O + BE + V3 + (by + S)**

Where **BE** changes according to the tense.

##  Master Passive Helping-Verb Chart

Memorize these patterns:

|Active|Passive|
|---|---|
|writes|is/am/are + written|
|is writing|is/am/are + being + written|
|has written|has/have + been + written|
|wrote|was/were + written|
|was writing|was/were + being + written|
|had written|had + been + written|
|will write|will + be + written|
|will have written|will + have been + written|
|can write|can + be + written|
|should write|should + be + written|
|must write|must + be + written|

The three words you should especially remember are:

**BE**

**BEING**

**BEEN**

### Simple / Future / Modal

**be + V3**

### Continuous

**being + V3**

### Perfect

**been + V3**

## Fast Exam Trick

First identify the tense.

Then select the passive pattern.

For example:

> They are repairing the road.

"are repairing" = Present Continuous.

Present Continuous Passive:

**am/is/are + being + V3**

Therefore:

> The road **is being repaired** by them.

Another:

> She has completed the project.

"has completed" = Present Perfect.

Present Perfect Passive:

**has/have + been + V3**

Therefore:

> The project **has been completed** by her.

##  Final Revision Sheet

Remember these **7 golden rules**:

1. **Object becomes the subject.**
2. **Main verb always becomes V3.**
3. **Tense remains the same.**
4. Use the correct form of **be**.
5. The original subject can come after **by**.
6. Change pronouns correctly: **I → me, he → him, she → her, we → us, they → them.**
7. Only verbs that take an object can normally be changed into passive voice.

The most important formula is:

**Active:**  
**Subject + Verb + Object**

↓

**Passive:**  
**Object + suitable form of BE + V3 + by + Subject**

And the easiest memory rule is:

**Simple → V3 with be**

**Continuous → being + V3**

**Perfect → been + V3**

**Modal → modal + be + V3**
