
### Subject

The person or thing that performs the action.

> **Rahul** bought a car.

Rahul = Subject

### Verb

The action.

> Rahul **bought** a car.

bought = Verb

### Object

The person or thing that receives the action.

> Rahul bought **a car**.

car = Object
####  How to find the object in a sentence

**1. Find the verb first.**  
The verb tells us the action.

Example:  
**Lata sings a song.**  
Verb = **sings**

**2. Ask “what?” or “whom?” after the verb.**  
The answer is usually the **object**.

- Lata sings **what?** → **a song** ✅ Object
- He called **whom?** → **Rahul** ✅ Object
- She bought **what?** → **a book** ✅ Object

A better rule is:

> **Subject + Verb + what/whom? = Object**


- **Who performs the action? → Subject**
- **What/whom receives the action? → Object**

Example:

**Lata sings a song.**

- Who sings? → **Lata** = Subject
- Sings what? → **a song** = Object
- **sings** = Verb
