| Term                | Meaning                                                           |
| ------------------- | ----------------------------------------------------------------- |
| Nebula              | Cloud of gas/dust                                                 |
| Protostar           | Forming young star                                                |
| Main Sequence       | Stable hydrogen-fusion phase                                      |
| Red Giant           | Expanded evolved low/intermediate-mass star                       |
| Supergiant          | Extremely large evolved massive star                              |
| Planetary Nebula    | Expelled shell from dying Sun-like star                           |
| White Dwarf         | Dense remnant of Sun-like star                                    |
| Supernova           | Powerful stellar explosion                                        |
| Neutron Star        | Dense compact stellar remnant                                     |
| Pulsar              | Rotating neutron star observed through periodic beams             |
| Magnetar            | Highly magnetized neutron star                                    |
| Black Hole          | Region where gravity prevents light escaping beyond event horizon |
| Brown Dwarf         | Substellar object unable to sustain normal H fusion               |
| Light-year          | Distance unit                                                     |
| Parsec              | Astronomical distance unit                                        |
| Luminosity          | Intrinsic energy output                                           |
| Apparent brightness | Brightness as observed                                            |
| Constellation       | Recognized pattern/region of sky                                  |
