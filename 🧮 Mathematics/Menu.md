# The spaced repetition system

When you learn something important, review:

```
Day 0
Day 1
Day 3
Day 7
Day 21
Day 45
```

AI or Anki can automate this.

Do this particularly for:

- vocabulary,
- idioms,
- one-word substitutions,
- GK,
- formulas,
- grammar exceptions.

This is an area where technology can genuinely save you time.
